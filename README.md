# 狂作－文學創作管理系統
本系統是一個檢視系統，完全免費，不會存檔，請務必保留您的創作原檔和匯出檔案。

一、文章、分類、欄位的自訂和新增

新增文章時可直接填寫內文，並同步建立投稿／得獎／出版紀錄。分類管理可新增、刪除、搬移欄位，也能自訂第一層分類，不再侷限於發表刊物、文學獎、出版收錄三種。

二、各種批次功能

批次新增可一次建立多篇文章；勾選文章後可用「批次系統」執行刪除、改分類、改文類、重算字數行數、增刪關鍵字，搭配「批次選取」依條件快速勾選、「反向選擇」一鍵反選；合併項目可把重複或誤植的文章合而為一。

三、匯出匯入和導入功能

「匯出 Excel」永久備份、「匯入 Excel」讀回備份。「從其他excel匯入」則能把您原本自己在用的表格匯入系統，自行對應欄位、預覽確認、比對相似欄位名稱，正式匯入前都能反悔。

四、篩選檢視更方便

精簡顯示、全部欄位／投稿狀況／得獎統計／出版紀錄可自由切換；關鍵字能直接點擊篩選；搜尋框、統計數字即時呈現，總表捲動也不怕跑版。

五、顏色自訂功能

可自由更換系統底色、表框顏色、框線顏色，也提供多組配色一鍵套用。
