# 狂作－文學創作管理系統
一、這是什麼系統

本系統是一個純瀏覽器端的檢視／整理工具，性質上更接近一份可以互動的 Excel，不是像 Notion、Google Sheets 那樣會自動存檔、自動同步的系統。

・不會自動存檔。所有編輯都只存在您目前這個瀏覽器的暫存空間裡，關閉分頁、換電腦、清除瀏覽器資料，都可能讓資料消失。唯一真正的存檔方式是「匯出 Excel」，請養成每次編輯完就匯出的習慣。

・不會上傳、不會同步。沒有帳號、沒有雲端、沒有後台，資料只存在您自己的裝置上，換裝置無法自動接續，必須用匯出的 Excel 檔在新裝置上「匯入 Excel」還原。

・一次只服務一個人，沒有多人協作、沒有版本衝突處理。

二、各按鈕的用途與識別邏輯

頁首：存檔與匯入匯出

・暫存：把目前畫面資料存進瀏覽器暫存空間，重新整理頁面不會遺失；但仍不等於永久存檔，換裝置或清除瀏覽器資料一樣會消失。

・匯出 Excel／匯入 Excel：本系統自己的存讀檔格式，兩者互相對應，不會做內容判斷。

・從其他excel匯入：把您自己整理的表格匯進來，需要手動把欄位一一對應；遇到看起來很像但打法不完全一樣的名稱（例如「靠悲」和「靠!悲」）會排在一起提醒您確認，避免漏掉。

・從TXT／DOCX檔案匯入：篇名取自檔名（自動去掉副檔名、頭尾括號、開頭破折號）；創作日期先嘗試從內文找日期格式，找不到才退而求其次用檔案的修改日期參考；文字編碼也會自動判斷（UTF-8、Big5、UTF-16），判斷有疑慮的檔案會標示提醒您檢查。

・直接貼上文本看看！：判斷邏輯是「第一行如果不是內文縮排開頭，就當作標題列」，因為稿件慣例上內文段落都有全形縮排，第一行沒有縮排通常就是篇名、作者、日期擠在一起的那一行。
新增與批次操作。

・＋新增文章：手動逐篇建立。

・批次新增：一次建立多篇。

・刪除（已選 N 篇）：直接對目前勾選的文章刪除；「批次系統」裡也有同樣的刪除功能，兩處入口，方便您勾選很多篇時就近找到。

・合併項目：把重複或誤植的文章合併成一篇，需要先勾選至少 2 篇。

・批次系統：收納改分類、改文類、重算字數行數、增刪關鍵字、批次選取（依新匯入的／同文類／某分類／某時間段／字數行數範圍快速勾選）這些功能，都需要先勾選文章才能用。

・反向選擇／清除選擇：反向選擇把目前的勾選狀態整個反過來；清除選擇一次取消全部勾選。

篩選與檢視

・全部欄位／投稿狀況／得獎統計／出版紀錄：切換要看哪一種分類的細節；切到分類檢視時，欄位標題會顯示目前累積的投稿／得獎數字，滑鼠移上去可看完整的已刊登／婉拒／還沒有結果細項。點擊刊物／獎項欄名稱，可以依照「已發表／得獎 › 婉拒／落選 › 還沒有結果 › 無作為」排序，方便快速看出哪些欄位還沒處理。

・精簡顯示／隱藏文類欄／隱藏創作日期欄：精簡顯示只留必要欄位；後兩者可以個別關掉這兩欄，讓手機畫面不會太擠（篇名欄目前是唯一能點進文章編輯的入口，所以沒有提供隱藏）。

・搜尋框：可查篇名或關鍵字，就算關鍵字欄位本身被隱藏了，也一樣查得到。

・分類管理：新增、刪除、搬移欄位，也能自訂第一層分類，不只發表刊物、文學獎、出版收錄三種。

個人化設定

・顏色設定：自訂系統底色、表框顏色、框線顏色，也有幾組配色一鍵套用。

・字－ 100% 字＋：調整整個系統畫面的文字大小；編輯文章畫面裡另外有一組只調整內文欄位字級的，兩者互不影響，各自記住您上次的設定。
